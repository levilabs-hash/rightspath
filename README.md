# RightsPath

Know what comes next.

RightsPath is a California residential tenancy prototype. It helps a renter turn a housing problem into structured facts, source-grounded information, next steps, and a letter they can review.

This version includes the application shell, design system, landing page, and case intake (jurisdiction, issue, and story). It does not yet analyze a story, retrieve legal rules, or generate a letter.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
```
